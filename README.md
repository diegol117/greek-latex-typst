# Greek Alphabet — Symbols, LaTeX & Typst Commands

A clean, fast, single-file web reference for the 24 letters of the Greek alphabet. Each letter shows its uppercase and lowercase symbols, its English and Spanish name, and its **LaTeX** or **Typst** command — copy any command with one click.

---

## ✨ Features

- **All 24 Greek letters** — uppercase + lowercase symbols, with English and Spanish names.
- **Two command syntaxes** — switch globally between **LaTeX** (`\alpha`, `\Gamma`) and **Typst** (`alpha`, `Gamma`) with a single toggle in the header. Cards stay clean and uncluttered.
- **One-click copy** — every command row has a copy button with a clear visual confirmation (green check, highlighted border, and a toast).
- **Variant forms included** — `\varepsilon`, `\vartheta`, `\varphi`, `\varpi`, `\varrho`, `\varsigma` (LaTeX) and `epsilon.alt`, `theta.alt`, `phi.alt`, `pi.alt`, `rho.alt`, `sigma.alt` (Typst).
- **Bilingual UI (EN / ES)** — full interface translation with automatic browser-language detection.
- **Persistent preferences** — language and syntax mode are saved in `localStorage`.
- **Shareable deep links** — preselect a mode with a URL parameter, e.g. `?mode=typst`.
- **Live search** — filter by symbol, English/Spanish name, or LaTeX/Typst command (variants included).
- **Responsive 3-column grid** — collapses gracefully to 2 columns and then 1 on smaller screens.
- **Dark, modern design** — high-contrast typography, gradient accents, subtle motion; respects `prefers-reduced-motion`.
- **Full SEO** — `title`, `description`, `keywords`, canonical, Open Graph, Twitter Card, and JSON-LD (`DefinedTermSet`) for the 24 letters.
- **Zero dependencies** — one HTML file, no build step, no frameworks.
